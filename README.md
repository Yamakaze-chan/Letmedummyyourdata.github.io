# **Letmedummyyourdata**   
These are functions you can use to generate your data:
- `randi(min, max)` Random integer
- `randf(min, max, numround)` Random float
- `randl([...Array...])` pick 1 item from the list randomly
- `{...String...}` It will keep all the text inside this braces
- ...and all the basic operators.
